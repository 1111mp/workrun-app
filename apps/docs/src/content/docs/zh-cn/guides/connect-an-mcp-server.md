---
title: 连接 MCP Server
description: 将本地 stdio 或远程 Streamable HTTP MCP Server 提供给 Agent。
---

MCP Server 是 Workrun 接入既有工具生态的方式。先在注册表连接并测试 Server，再让特定 Agent 选择其发现的工具；不要将一个连接自动暴露给所有 Agent。

## 添加本地 stdio Server

1. 打开顶部账户菜单中的 **MCP 服务器**；
2. 点击 **添加服务器**；
3. 填写可识别的名称和描述，例如 `GitHub MCP` / `搜索与管理 GitHub 仓库`；
4. 在 **连接类型** 选择 **本地进程（stdio）**；
5. 填写启动命令；参数每行一个；需要的环境变量按 `KEY=value` 每行一个填写；
6. 保持 **启用此服务器** 打开，点击 **测试连接**；
7. 确认已发现的工具数量和名称，再保存并启动。

环境变量值会随 Server 配置加密保存。不要将密钥写进命令参数、工作流输入或截图。

## 添加远程 HTTP Server

在 **连接类型** 选择 **远程端点（HTTP）**，填入支持 Streamable HTTP 的公开端点 URL。身份验证可选无认证、Bearer 令牌或 OAuth。OAuth 保存后会在浏览器中完成授权；授权成功后回到 Workrun 重新测试连接。

## 让 Agent 使用工具

1. 确保 Server 状态为“在线”；
2. 选中目标 Agent，打开 **工具**；
3. 在 **可用工具** 中勾选该 Server 发现的具体工具；
4. 设置调用上限和每次工具调用的超时；
5. 运行一个最小输入，并在运行面板检查工具参数、返回值和审批记录。

## 排查

- **测试连接失败：** 在本机终端先确认命令可启动；检查参数换行、工作目录和环境变量名称。
- **Server 在线但没有工具：** 连接成功不代表 Server 声明了工具；查看发现工具列表和 Server 日志。
- **Agent 看不到工具：** Server 必须已启动，并且工具需要在该 Agent 的工具列表中被显式选择。
- **远程授权循环：** 重新授权后测试连接；确认回调浏览器与 Workrun 使用的是同一个本地配置。
