---
title: 人工审批与恢复
description: 在需要人负责的节点暂停运行，并从检查点安全继续。
---

并非每个步骤都应该自动执行。对外发送内容、改动生产数据、处理高风险分类或执行高权限工具时，应把决定交给人。

## 配置 Human Review

1. 从节点面板拖入 **Human Review**，连接到需要决定的上游节点；
2. 在右侧检查器的 **审核请求** 中填写明确标题和审核说明；
3. 将 **内容键** 设为要审核的 State 字段，例如 `recommendation`；
4. 在 **上下文键** 中填写审核人需要参考的字段，例如 `category, priority, source_url`；
5. 如需审核人直接修订内容，开启 **允许编辑**；
6. 将“批准”和“拒绝”两个输出分别连接到下一步，不要只连接批准。

运行到该节点时，状态会被写入本地 SQLite 检查点，运行面板显示“等待输入”。提交审核结果后，Workrun 从该检查点继续，已完成节点不会重跑。

## 配置 Ask User Question

当需要用户选择路径而不是审核一段内容时，使用 **Ask User Question**：填写问题、可选上下文和选项。每个选项对应一个画布输出；即使之后修改显示标签，选项标识仍保持稳定，避免已保存分支失效。

工具调用也可以要求每次确认。若用户拒绝，拒绝原因会反馈给 Agent，使其可以采取替代方案，而不是静默失败。

设计审批时，请写清三件事：审核人要看什么、可以做什么、拒绝后流程会如何继续。

> **素材占位 · 视频 `human-review/01-pause-edit-resume.mp4`（30–45 秒）**  
> 画面：运行在 Human Review 暂停，审核人查看上下文、编辑建议后批准，流程从检查点继续。  
> 用途：强调不是“重新运行”，而是“继续原运行”。
