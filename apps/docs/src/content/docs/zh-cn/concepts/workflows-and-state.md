---
title: 工作流与状态
description: 通过显式状态和节点边界，让流程保持可读、可控与可恢复。
---

工作流由画布上的节点与连接组成。常用节点包括 `Start`、`End`、`Agent`、`Process`、`If/Else`、`Switch`、`Human Review`、`Ask User Question`、`Subworkflow` 和 `Terminate`。

## 显式状态，而不是隐式上下文

每个节点拥有隔离的状态命名空间。只有显式发布的字段才能被后续节点读取；节点也需要被授予读取权限。这能减少「某个步骤悄悄改变了全部上下文」带来的不可预测性。

输入、输出和节点结果可由 JSON Schema 描述。让 Schema 尽早进入流程，可以在运行前发现分支、图结构和数据形状的问题。

## 暂停与恢复

人工审核或提问会将运行状态写入本地 SQLite 检查点。提交审核结果后，Workrun 从暂停点继续，而不是重新执行已经完成的节点。失败的后台运行也可以从检查点重试。

> **安全边界：** 标记为敏感的输入或输出会被加密保存，并在模型、工具与界面中默认使用脱敏视图。不要在不受信任的 App 中处理你不愿授予它访问权的数据。
