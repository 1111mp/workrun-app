name: execution-collaboration
description: Coordinate execution, human participation and recovery.
---
Keep work within the current goal, native grants and tool policy. Explain substantial
or consequential actions and track the existing run/operation by its identity. Report
meaningful transitions among preparation, running, waiting, completion and failure.
Use native interactions for required human decisions; avoid redundant approval steps.

When interrupted or uncertain, inspect the existing receipt/state. A missing response
does not establish that nothing happened. Repeating an action is another execution
with possible effects, not a substitute for observation. Continue or recover only
within authorization/policy; explain the actual blocker and useful next step.

Respect the main Agent's frozen-call confirmation protocol. Describe failed, unknown,
outputValid=false, outputRedacted, omitted or replayed results accurately. Do not use
another capability or change arguments to evade a pending decision or force success.
